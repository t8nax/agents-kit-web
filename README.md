# agents-kit-web

Веб-панель оператора над базами знаний agents-kit: рабочие копии, бэклог,
задачи, сессии Claude Code и проблемы баз — в одном окне браузера.

Панель работает только на своей машине: слушает `localhost`, из сети её не видно.

Панель работает над [agents-kit](https://github.com/t8nax/agents-kit): команда ниже ставит и кит, и панель.

## Установка одной командой

Откройте Windows PowerShell и выполните:

```powershell
iex ((irm https://raw.githubusercontent.com/t8nax/agents-kit-web/master/scripts/install.ps1).TrimStart([char]0xFEFF))
```

Установщик сначала проверяет, что на машине есть [Claude Code](https://claude.com/claude-code) с выполненным входом.
Если нет, он говорит, что сделать, и больше ничего не делает. Потом через winget ставит недостающее из того, чем панель
работает, — git и PowerShell 7. Если кита нет, ставит его из магазина плагинов Claude Code, как описано в
[README кита](https://github.com/t8nax/agents-kit); уже стоящий кит не трогает. Затем скачивает готовую сборку
последнего выпуска панели с GitHub и ставит её в `%LOCALAPPDATA%\agents-kit-web\app`. Ничего не собирается: .NET и Node.js на машине не нужны. В конце открывается
http://localhost:5080. Базу знаний под китом заводят в Claude Code командой `/onboard` в каталоге проекта.

Вход в Claude Code установщик узнаёт по ключу, который появляется после обычного входа командой `/login`. Если Claude
Code у вас работает иначе — например, через корпоративный шлюз с токеном в настройках, — установщик сочтёт, что входа
нет. Тогда ставьте панель вручную, как описано ниже.

## Установка вручную

### Что нужно на машине

- Windows 10 или 11.
- [PowerShell 7](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) — команда `pwsh`.
  Встроенного Windows PowerShell 5.1 мало.
- [git](https://git-scm.com/).
- [Claude Code](https://docs.claude.com/claude-code), в котором выполнен вход: команда `claude` в новом окне PowerShell
  должна запускаться и отвечать.
- Установленный [agents-kit](https://github.com/t8nax/agents-kit) и хотя бы одна база знаний под ним — как поставить
  кит, написано в его README.

Необязательно:

- [Windows Terminal](https://aka.ms/terminal) — в нём панель открывает сессии. Без него откроется обычное окно PowerShell.
- [VS Code](https://code.visualstudio.com/) — им панель открывает рабочие копии и файлы. Другие редакторы, в том числе
  Cursor, панель открывать не умеет.

### Постановка

Скачайте `agents-kit-web-win-x64.zip` последнего выпуска со страницы
[выпусков](https://github.com/t8nax/agents-kit-web/releases/latest) и поставьте его:

```powershell
$target = "$env:LOCALAPPDATA\agents-kit-web\app"
Expand-Archive agents-kit-web-win-x64.zip "$target.new"
Copy-Item "$target.new\scripts\deploy.ps1" $env:TEMP
pwsh -NoProfile -File "$env:TEMP\deploy.ps1" -Source "$target.new" -Target $target
```

Когда появится «Панель запущена», откройте http://localhost:5080.

Панель запускается сама при каждом входе в Windows — для этого заводится задача Планировщика заданий
`agents-kit-web panel`. Прав администратора не нужно.

## Первоначальная настройка

Всё настраивается в разделе «Настройки» панели.

1. **Путь к киту.** Нажмите «Найти автоматически» — панель поищет кит среди навыков и плагинов Claude Code и подставит
   путь. Нажмите «Сохранить». Если кит лежит в другом месте, укажите его каталог через «Обзор…». Без пути к киту панель
   не проверяет проблемы баз и не заводит и не убирает рабочие копии.
2. **Базы знаний.** Укажите каталог базы — тот, в котором лежит `agents-kit.json`, — и нажмите «Добавить». Так для
   каждой базы, которую хотите видеть в панели.

Настройки хранятся в `%APPDATA%\agents-kit-web` и переживают обновления и переустановку панели.

## Проверить, что всё работает

1. Задайте вопрос по базе через «Спросить». Это обычный запуск Claude — если ответ пришёл, Claude из панели работает.
2. Возьмите в работу задачу из бэклога. Задачи идут в фоновых сессиях Claude Code: если сессия завелась и видна в
   панели, работает и это.

Если что-то упало, панель покажет текст ошибки — начинать разбор с него.

## Обновление

Панель сама подсказывает, когда на GitHub вышла сборка новее, и обновляется кнопкой в «Настройках»: скачивает готовую
сборку и ставит её. Канал выбирается там же: «Стабильный» — выложенные выпуски, «Бета» — свежие, ещё не выложенные.

Панель, поставленная раньше сборкой из исходников, переходит на готовые сборки тем же обновлением кнопкой.

## Если Claude Code запускается у вас по-особому

Панель запускает Claude Code так же, как вы в терминале, — командой `claude`, с настройками вашего профиля Claude Code.
Поэтому главное условие одно: простой `claude` в новом окне PowerShell работает.

- **Корпоративный шлюз** (например, LiteLLM), настроенный в пользовательском `settings.json` Claude Code, панели не
  мешает: она пойдёт через него же. Не будет видно только остатков лимитов подписки — за ними панель обращается к
  Anthropic напрямую.
- **Лаунчер-скрипт**, который только проверяет настройки и запускает `claude`, панели не нужен: ей достаточно, чтобы
  настройки были верны. Если ваш скрипт при запуске ещё и что-то подкладывает Claude сам — переменные окружения,
  ключи, — панель этого не повторит, и работать из неё Claude не будет.
- **Переменные окружения** Windows, которые меняют модель или провайдера Claude, панель видит так же, как любой новый
  терминал.

## Удаление

```powershell
Unregister-ScheduledTask -TaskName 'agents-kit-web panel' -Confirm:$false
Get-Process AgentsKitWeb.Api -ErrorAction SilentlyContinue | Stop-Process
Remove-Item "$env:LOCALAPPDATA\agents-kit-web" -Recurse -Force
```

Настройки в `%APPDATA%\agents-kit-web` удаляются отдельно, если они больше не нужны.
